# 엔트리-파이썬 단축키 모음

## 윈도우즈용

| **기능**                 | **단축키**                                        |
| ---------------------- | ---------------------------------------------- |
| 들여쓰기 / 내어쓰기 단계 조정      | tab   ,   shift + tab                          |
| 블록 / 모양 / 소리 / 속성 탭 선택 | Alt + 1  ,   Alt + 2  ,   Alt + 3  ,   Alt + 4 |
| 이전 / 다음 오브젝트 선택        | Alt + [  ,   Alt + ]                          |
| 블록 코딩 / 엔트리파이선 모드 변경   | Ctrl + [   ,   Ctrl + ]                       |
| 실행                     | Ctrl + R                                       |
